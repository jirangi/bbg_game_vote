1. 사용자 인증 및 보안 (Authentication)
PIN 로그인 시스템: 별도의 아이디 없이 부여받은 고유 PIN 번호와 비밀번호로 간편하게 로그인합니다.

기본 비밀번호: 신규 생성된 유저의 초기 비밀번호는 1234로 설정됩니다.

PIN 찾기: 로그인 화면 하단에서 전체 유저의 PIN 번호와 이름을 확인할 수 있는 모달을 제공합니다.

자동 로그인: 브라우저 로컬 스토리지를 활용하여 매번 로그인할 필요 없이 세션을 유지합니다.

2. 마이 프로필 (User Customization)
닉네임 변경: 서비스 내에서 사용할 이름을 자유롭게 수정할 수 있습니다.

커스텀 아이콘: 이미지 URL을 입력하여 자신만의 프로필 사진을 설정합니다.

기본값 제공: 아이콘 미설정 시 귀여운 보드게임 주사위 아이콘이 기본으로 적용됩니다.

실시간 반영: 프로필을 변경하면 내가 쓴 모든 댓글과 명예의 전당의 아이콘이 즉시 업데이트됩니다.

3. 게임 랭킹 시스템 (Ranking System)
카테고리 분류: 보드게임, 지니어스, 방탈출, 머더 미스테리 4가지 섹션을 제공합니다.

신뢰도 알고리즘: 평가가 3개 이상 쌓인 게임을 신뢰할 수 있는 데이터로 간주하여 점수가 낮더라도 최상단에 먼저 노출합니다. (1~2개 평가는 하단 배치)

자동 제외 로직: 평가가 0개인(데이터가 없는) 게임은 리스트에 노출하지 않아 랭킹의 질을 관리합니다.

랭킹 메달: 1, 2, 3위에 각각 🥇, 🥈, 🥉 메달을 부여하여 시각적 성취감을 줍니다.

데이터 보정: 점수 계산 시 상하위 점수를 제외한 절사평균 등을 적용하여 극단적인 평점에 의한 왜곡을 방지합니다.

4. 상세 정렬 및 필터 (Sorting & Filtering)
4방향 상세 정렬: 랭킹 페이지 상단의 스크롤 바를 통해 원하는 기준을 선택합니다.

점수순: 재미 점수 기준 내림차순/오름차순.

난이도순: 난이도 별점 기준 내림차순(어려운순)/오름차순(쉬운순).

가로 스크롤 UI: 모바일 환경에서도 버튼이 깨지지 않도록 필터 영역에 가로 스크롤을 적용했습니다.

5. 게임 평가 및 댓글 (Evaluation & Social)
개별 평가: 각 게임의 점수(0~100)와 난이도 별점(0~5.0)을 따로 입력할 수 있습니다.

반 별 시각화: 난이도를 0.5점 단위의 정밀한 별 모양(★, ⯪, ☆)으로 표시합니다.

한줄평 시스템: 게임별로 자유롭게 댓글을 남길 수 있으며, 유저 프로필 아이콘이 함께 표시됩니다.

익명 기능: 특정 댓글을 남길 때 '익명 작성'을 체크하여 정보를 숨길 수 있습니다.

좋아요(🍕): 인상 깊은 댓글에 피자 아이콘으로 좋아요를 눌러 공감을 표시합니다.

6. 명예의 전당 (Hall of Fame)
3대 부문 랭킹: 베스트 댓글 왕(피자 수), 최다 투표 왕(평가 횟수), 최다 게임 등록 왕(기여도)을 집계합니다.

시각적 강조: 금/은/동 순위에 따라 카드 크기를 확장하고 전용 테두리 색상을 입혀 특별하게 대우합니다.

프로필 노출: 상위권 유저들의 개성 있는 아이콘을 메인 화면에 크게 보여줍니다.

딥 링크(Deep Link): 명예의 전당에 노출된 베스트 댓글을 클릭하면, 해당 게임의 카테고리로 자동 이동하여 댓글 팝업을 즉시 오픈합니다.

7. 자유 게시판 (Community Board) - NEW
자유 대화: 게임 평가와 별개로 모임 공지나 일반 대화를 나눌 수 있는 공간입니다.

모임 모집: "2월 19일 영등포팟" 처럼 구체적인 날짜와 인원 모집 글을 남기고 관리합니다.

결과 기록: 모임 후 승패 기록이나 간단한 후기를 자유롭게 포스팅할 수 있습니다.

8. 관리자 시스템 (Admin Controls)
관리자 전용 UI: PIN 100 계정 로그인 시에만 홈 화면에 [⚙️ 관리] 버튼이 활성화됩니다.

유저 관리: 실시간으로 새로운 인원을 추가(이름 입력 시 PIN 자동 생성)하거나, 명단에서 삭제할 수 있습니다.

게임 관리: 카테고리에 있는 게임의 이름을 수정하거나 잘못된 데이터를 관리합니다.

📱 모바일 최적화 (Responsive Design)
2행 평가 레이아웃: 좁은 화면에서 게임 이름과 별점이 겹치지 않도록 평점/난이도 영역을 상하로 배치했습니다.

독립적 터치 영역: 점수 클릭과 난이도 클릭 영역을 확실히 구분하여 모바일 오클릭을 방지했습니다.
